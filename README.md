# 🚀 ReactJS Projects  

This repository contains multiple small ReactJS projects I built while learning and practicing React.  
Each folder is a standalone project that you can explore and run locally.  

---

## 📂 Projects  

• **[⏰ Digital Clock](./digitalClock)**  
  ◦ A simple React digital clock that updates in real-time.  

• **[🎬 Netflix Clone](./netflixClone)**  
  ◦ A basic Netflix UI clone built with React and styled components.  

• **[🎵 Spotify Clone](./spotify-clone)**  
  ◦ A Spotify-inspired music player with playlists, songs, and custom components.  

• **[⏱️ Stopwatch](./stopWatch)**  
  ◦ A stopwatch app with start, stop, and reset functionality.  

• **[📝 To-Do List](./toDoList)**  
  ◦ A to-do list app where you can add, delete, and mark tasks as complete.  

---

## ⚡ How to Run Any Project  

1. **Navigate into the project folder**  
   cd spotify-clone  

2. **Install dependencies**  
   npm install  

3. **Start the project**  
   npm run dev
